UWP Windows Explorer

The UWP (Universal Windows Platform) version of Windows Explorer is a modern, touch-friendly file manager introduced with Windows 10. It features a clean interface with a hamburger menu, quick access to frequently used folders, and seamless integration with OneDrive and cloud services. Unlike the classic Win32 Explorer, the UWP version was designed for tablets and touch devices, offering larger touch targets and a simplified navigation experience.

Step 1. Right-click on your desktop, select New, and then choose Shortcut from the context menu.

Step 3. Click Finish to create the shortcut.

Step 4. Right-click the newly created shortcut and select Properties.

Step 5. In the Target field, check if the path is correct.

SlideToShutdown.exe

SlideToShutdown.exe is a hidden utility built into Windows 8, 8.1, and 10. When launched, it displays a lock screen with a "slide to shut down" gesture, similar to the swipe-to-power-off feature on mobile devices. It can be run directly from the System32 folder or pinned to the taskbar for quick access. This tool is especially useful for touchscreen devices and tablets, providing an elegant and intuitive way to power down your PC.

Step 1. Press Win + R to open the Run dialog, type SlideToShutdown.exe, and hit Enter. The screen will dim, and a slide-down interface will appear.

Step 2. Click and Hold to slide the piturce Down with your lockscreen wallpaper , then drag it down to the bottom of the screen. Release the mouse button to shutdown your computer.

edit.exe (MS-DOS Editor)

edit.exe is the MS-DOS Editor, a classic text editor that runs inside the Command Prompt (cmd.exe). Originally introduced with MS-DOS 5.0 in the June of 1991, it provides a full-screen text editing interface with menus, mouse support, and keyboard shortcuts. Microsoft recently brought it back in newer Windows 11 builds, allowing users to launch it directly from the command line by typing "edit". It's a lightweight and nostalgic tool for editing text files, batch scripts, and configuration files without needing a modern IDE.

Step 1. Open the Command Prompt (cmd.exe) by pressing Win + R and typing cmd.

Step 2. Type edit and press Enter to launch the Command prompt based Editor.

The Hidden MS-DOS Icons Still Here After All These Years

Deep inside every modern Windows installation, some very old icons from the MS-DOS era are still hiding. These DLL files have shipped with Windows since the Windows 95 days (and even earlier), and they are still sitting in your System32 folder today you can view them with any icon viewer, or use them in shortcuts via %windir%\System32\pifmgr.dll and others :

  • pifmgr.dll Windows 95 era icons, including the classic MS-DOS icon (the one used for this card!).
  • moricons.dll icons even older than Windows 95, dating back to the Windows 3.x / MS-DOS days.
  • mmcndmgr.dll old Microsoft Management Console node manager icons.
  • compstui.dll old common property sheet UI icons, still used by printer drivers.

Microsoft keeps shipping them for backwards compatibility, so even on Windows 11 these little pixel-art relics from the DOS age are still one right-click away. A true piece of living history!

Step 1. Create a new folder in your Desktop .

Step 2. Right-click the folder, select Properties, and click the Customize tab. Click Change Icon.

Microsoft's Hidden Offline Antivirus

Windows already ships two free antivirus tools that Microsoft almost never mentions. They run the same scanning engine, they cost nothing, and neither one replaces Windows Defender they are the on-demand companion you reach for when Defender is running but you still do not trust the machine.

  • Microsoft Safety Scanner the standalone download, and the one that actually is msert.exe. It looks for all kinds of malware instead of a fixed list of families, offers quick, full and custom scans, and installs nothing at all: the executable is the tool, so deleting the file removes it.
  • Windows Malicious Software Removal Tool (MSRT) the same engine on a schedule. Windows Update delivers it on the second Tuesday of every month, it runs quietly in the background, and it only speaks up if it finds something. It targets prevalent malware families specifically, which is exactly why it is no substitute for a real antivirus. Its standalone package ships as Windows-KB890830-x64-V5.145.exe (KB890830).

Running MSRT from the command line. Worth being precise here: the Safety Scanner is download-and-click only Microsoft documents it as a GUI tool with no switches of its own, so the msert.exe /F commands you find on blogs are not Microsoft's. The MSRT is the one with an officially documented switch table, in KB890830. Download the standalone MSRT package, open an elevated Command Prompt right-click cmd.exe and choose Run as administrator change into the folder, and force an extended scan that also cleans what it finds :

cd %USERPROFILE%\Downloads
Windows-KB890830-x64-V5.145.exe /F:Y

That is every switch Microsoft actually documents for it :

  • /F forces an extended scan of the computer.
  • /F:Y the same extended scan, and cleans any infections that are found automatically.
  • /N detect-only mode: the malicious software is reported to you, but nothing is removed.
  • /Q (or /quiet) quiet mode; suppresses the user interface entirely.
  • /? displays a dialog box that lists the command-line switches.

Results land in %SYSTEMROOT%\debug\msert.log for the Safety Scanner, and %windir%\debug\mrt.log for the MSRT. Official pages : Safety Scanner · MSRT (64-bit) · KB890830

Bonus. There is a third rescuer already sitting inside Windows, and it is the only one of the three that can actually see a rootkit. Microsoft Defender Offline reboots the machine into the Windows Recovery Environment and runs a quick scan from outside the Windows kernel, so malware that hides from a running system rootkits, bootkits, anything that has taken over the master boot record has nowhere left to sit. It is the escalation step for when msert.exe and the MSRT both come back clean and you still do not believe it.

Step 1. Save your work. This one restarts the machine.

Step 2. Open Windows Security → Virus & threat protection → Scan options → pick Microsoft Defender Offline scan → Scan now.

Step 3. Or skip the GUI entirely and trigger the same reboot from an elevated PowerShell :

Start-MpWDOScan

It takes roughly 15 minutes and then boots back into Windows by itself. Results show up under Protection history. Worth knowing: offline mode only ever runs a quick scan there is deliberately no full or custom option.

And one gotcha that costs people an hour : if the Windows Recovery Environment happens to be disabled, the offline scan will not run and Windows reports no error at all you just restart into normal Windows and nothing happened. Check it and turn it back on with :

reagentc /info
reagentc /enable

Microsoft's own notes on it are at learn.microsoft.com/en-us/defender-endpoint/microsoft-defender-offline.

ExplorerPatcher

The Project from github : https://github.com/valinet/explorerpatcher/

ExplorerPatcher is a free, open-source utility that brings back classic Windows 10 functionality to Windows 11. It can restore the Windows 10 taskbar, system tray, File Explorer UI, and more all with a familiar right-click "Properties" window for tweaking everything. It is a must-have tool for anyone who prefers the old Windows look and feel.

Bonus: someone discovered a hidden registry value that reverts the Notification Center itself to the classic Windows 10 UI no third-party tools needed. Open regedit, go to:

Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Control Center

  • Create a new DWORD (32-bit) Value named UseLiteLayout.
  • Set it to 1 for the Windows 10 Notification Center UI.
  • Set it to 0 for the Windows 11 Notification Center UI (default).

Or save this as a .reg file and double-click it:

Windows Registry Editor Version 5.00
    
    [HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Control Center]
    "UseLiteLayout"=dword:00000001

Restart Explorer (or sign out and back in) for the change to take effect.
